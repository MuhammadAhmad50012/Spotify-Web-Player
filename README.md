#Spotify Clone 

A modern Spotify-inspired music player built using **HTML, CSS, and Vanilla JavaScript**. This project provides a clean and responsive music streaming interface with dynamic playlists, album browsing, and playback controls.

## Features

- 🎧 Dynamic music library
- 📀 Album cards generated from JSON
- ▶️ Play / Pause songs
- ⏮ Previous & Next controls
- 🎚 Seek bar
- 🔊 Volume control & Mute
- 📱 Responsive design
- 🎵 Album cover images
- 📂 Multiple playlists
- ⚡ Fast and lightweight

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- JSON
